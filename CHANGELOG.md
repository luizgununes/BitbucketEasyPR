# Changelog

All notable changes to Bitbucket EasyPR will be documented in this file.

## 2.0.1

- Add Visual Studio Marketplace and Open VSX publishing automation.
- Improve Marketplace search keywords and package metadata.
- Modernize the extension packaging toolchain and reduce the VSIX size.
- Add explicit command activation events for registry compatibility.

## 2.0.0

- Replace Bitbucket app passwords with scoped Atlassian API tokens.
- Add credential reconfiguration and clearing commands.
- Improve validation, retry handling, and API error messages.
